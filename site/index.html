Kerabit

A 3D engine that stays small on the outside.

Native Rust. Tiny game API. Real wgpu depth — scenes, editor, physics, audio, shadows — without dragging a 20GB toolchain into your life.

Start in 30 min View on GitHub

github.com/AJpro774/kerabitengine

Alpha — clone & cargo

Install Rust stable via rustup, then clone and run. Same commands as the README — no alternate installer. 

git clone https://github.com/AJpro774/kerabitengine.git
cd kerabitengine
cargo run -p kerabit --example hello
cargo run -p kerabit-editor
cargo run -p reach

Full stranger path (site → hello → editor): Getting Started.

Download Reach

Player zips need no Rust toolchain. Unzip and run. Authors who want to rebuild locally use the packaging scripts in the repo.

GitHub Releases macOS script Windows script

Expected artifacts when published: Reach-macos.zip (Reach.app) and Reach-windows.zip (reach.exe + levels/ + assets/). Build yourself with ./scripts/package-reach.sh or pwsh ./scripts/package-reach-windows.ps1. CI can attach both via the package-reach workflow (workflow_dispatch).

Built for authors

Spawn meshes, light a scene, react to input. The hard parts — GPU pipelines, world matrices, scene reload, soft shadows — stay inside the crate. 

Kerabit::new("Demo")
    .spawn(Entity::new("cube").mesh(Mesh::cube()).at(0.0, 0.5, 0.0))
    .camera(Camera::perspective(60.0).look_at([4.0, 3.0, 6.0], [0.0, 0.0, 0.0]))
    .run(|ctx| { /* your game */ });
