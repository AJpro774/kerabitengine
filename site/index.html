Kerabit

A 3D engine that stays small on the outside.

Native Rust. Tiny game API. Real wgpu depth — scenes, editor, physics, audio, shadows — without dragging a 20GB toolchain into your life.

View on GitHub Clone & run

Alpha v1.0 — clone & cargo

Install Rust stable via rustup, then clone and run. Same commands as the README — no alternate installer. 

git clone https://github.com/AJpro774/kerabitengine.git
cd kerabitengine
cargo run -p reach
cargo run -p surge
cargo run -p kerabit-editor

Reach & Surge

Flagship micro-games ship with the engine. Author levels in kerabit-editor, play on macOS, keep the challenge sharp. 

cargo run -p reach
cargo run -p surge
cargo run -p kerabit-editor

Built for authors

Spawn meshes, light a scene, react to input. The hard parts — GPU pipelines, world matrices, scene reload, soft shadows — stay inside the crate. 

Kerabit::new("Demo")
    .spawn(Entity::new("cube").mesh(Mesh::cube()).at(0.0, 0.5, 0.0))
    .camera(Camera::perspective(60.0).look_at([4.0, 3.0, 6.0], [0.0, 0.0, 0.0]))
    .run(|ctx| { /* your game */ });
