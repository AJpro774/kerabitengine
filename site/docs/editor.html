Editor guide

kerabit-editor is the level tool for Reach, Surge, and your own .kerabit.json scenes. Supported from source on macOS, Windows, and Linux. It is a dev tool — not bundled in Reach.app or reach.exe.

Launch

cargo run -p kerabit-editor

Same command on all three OSes. File → Open a scene under games/*/levels/. Settings (gizmo snap, etc.) persist to ~/.kerabit/editor.json (Windows: %USERPROFILE%\.kerabit\editor.json). A Windows zip is Kerabit-editor-windows.zip from pwsh ./scripts/package-windows.ps1 — keep games/ next to the exe. Mac → PC: WINDOWS.md.

Viewport

  • Orbit — right mouse drag
  • Pan — middle mouse drag
  • Zoom — scroll wheel
  • Select — click an entity; Shift+click multi-select
  • Gizmos — W move · E rotate · R scale
  • Place cube — toolbar, then click the ground plane

Edit tools

  • Ctrl+Z / Ctrl+Shift+Z — undo / redo for scene mutations
  • Edit → Duplicate selected
  • Edit → Align X / Y / Z (needs 2+ selection; aligns to primary)
  • File → Save Prefab / Instance Prefab — .kerabit.prefab.json (samples in games/reach/prefabs/)
  • File → Save writes .kerabit.json

Script panel

Menu Script → Show panel. The panel is a multiline Juni editor (not a one-line path). Open / Save, Check syntax, Reload from disk. Inspector and environment fields expose extras.script. Play compiles attached scripts and hot-reloads when the .juni file changes on disk. Guide: Juni scripting.

Assets

The Assets window is a project-rooted file browser for meshes, textures, and HDR. Browse / Edit / Clear in the inspector pick from that tree. Paths written into the scene stay relative to the scene file.

Meshes

Inspector mesh files: OBJ, glTF / glb, and FBX.

Play

Toolbar Play runs the open scene in a child window with no builtin HUD or fly camera — the scene camera and Juni UI are the game. Dirty scenes use a temp snapshot so you do not have to save first. Escape (or Stop) returns to edit with selection restored.

Mods

Menu Mods lists folder packs (mod.kerabit.json): enable, Open, Play, New pack. Guide: Community mods.

Authoring Reach

Levels live in games/reach/levels/ and must be registered in games/reach/src/main.rs (LEVEL_FILES + CHAPTERS). Role tags:

  • player, goal, ground, wall, hazard
  • Keep unit-cube players (half = 0.5)
  • Leave dodge gaps ≥ 1.0

Best times: ~/.kerabit/reach_progress.txt. Full ownership notes: repo CONTRIBUTING.md.
