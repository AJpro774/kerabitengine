Editor guide

kerabit-editor is the level tool for Reach, Surge, and your own .kerabit.json scenes. It is a dev tool — not bundled inside player zips.

Launch

cargo run -p kerabit-editor

File → Open a scene under games/*/levels/. Settings (gizmo snap, etc.) persist to ~/.kerabit/editor.json (Windows: %LOCALAPPDATA%/Kerabit/).

Viewport

  • Orbit — right mouse drag
  • Pan — middle mouse drag
  • Zoom — scroll wheel
  • Select — click an entity; Shift+click multi-select
  • Gizmos — W move · E rotate · R scale
  • Place cube — toolbar, then click the ground plane

Edit tools

  • Ctrl+Z / Ctrl+Shift+Z — undo / redo for scene mutations
  • Edit → Duplicate selected
  • Edit → Align X / Y / Z (needs 2+ selection; aligns to primary)
  • File → Save Prefab / Instance Prefab — .kerabit.prefab.json (samples in games/reach/prefabs/)
  • File → Save writes .kerabit.json

Play

Toolbar Play runs the open scene in a child window. Dirty scenes use a temp snapshot so you do not have to save first. Escape (or Stop) returns to edit with selection restored.

Authoring Reach

Levels live in games/reach/levels/ and must be registered in games/reach/src/main.rs (LEVEL_FILES + CHAPTERS). Role tags:

  • player, goal, ground, wall, hazard
  • Keep unit-cube players (half = 0.5)
  • Leave dodge gaps ≥ 1.0

Best times: ~/.kerabit/reach_progress.txt. Full ownership notes: repo CONTRIBUTING.md.
