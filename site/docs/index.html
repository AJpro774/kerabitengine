Learn Kerabit in one sitting

Same install as the README: rustup, clone, then cargo run on macOS, Windows, or Linux. Reach player zips are macOS and Windows only. Local loop: hello → Spark (script-first) → editor → Reach (16 levels / 4 chapters).

  • Getting Started Site → clone → hello cube → editor in under 30 minutes.
  • API tour Spawn, lights, scenes, input, physics, audio, Juni — the public surface.
  • Juni scripting 3.0 host API, typed scripts compiled to WASM, Spark, hot-reload, editor panel.
  • Editor guide Viewport, Juni editor, Assets, FBX, Play, mods, Reach levels.
  • Community mods Folder + mod.kerabit.json, git clone into mods/, catalog, editor Mods window.

Deeper contracts live in the repo: API.md, ARCHITECTURE.md, CHANGELOG.md, ROADMAP.md.
