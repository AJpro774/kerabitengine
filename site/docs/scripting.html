Rhai scripting

Kerabit 2.0 embeds Rhai with a rich host API so you can ship small games mostly in .rhai. The public Rust API from 1.0 stays frozen. egui stays in kerabit-editor.

Try it

cargo run -p kerabit --example hello_rhai
cargo run -p spark

hello_rhai spins a cube. Spark is the script-first proof game (WASD, goal pad, hazards) — logic in games/spark/scenes/spark.rhai.

Attach a script

Put a path in extras.script (or components.script) on the scene root or an entity. Paths are relative to the .kerabit.json file for both load_scene and apply_scene. 

{
  "version": 1,
  "extras": { "script": "game.rhai" },
  "entities": [{ "name": "player", "extras": { "script": "player.rhai" } }]
}

Prefer fn init() / fn update(). Use set / get / has for persistent values across frames. Entity scripts bind self.

When they run

Each frame: Rust run closure, then every loaded script, then render. Missing names are no-ops. Parse errors fail load; runtime errors set ctx.script_error(). Loaded files hot-reload when their mtime changes.

Host API (Frozen for 2.0)

  • dt() · quit() · reload_scripts()
  • key_down / key_pressed · mouse_pos · mouse_button_down / pressed
  • pos / get_pos · scale · enabled · has_tag · exists · names_with_tag
  • rotate_* · translate · set_pos · set_scale · set_enabled · add_tag / remove_tag
  • despawn · spawn_cube / spawn_cube_ex · spawn_plane · spawn_prefab
  • move_planar · register_box (static AABB from entity scale)
  • play / play_at · spawn_particles · set_camera
  • ui_text / ui_rect (normalized coords; ASCII text only)
  • set / get / has — persistent store

Editor

Script menu → Show panel, Check syntax, Reload from disk. Play loads scripts and auto-reloads on file save. Details: Editor guide.
