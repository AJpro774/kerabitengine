Getting Started

Stranger path: this site → clone → hello cube → editor. Budget about 30 minutes on a machine with a working GPU driver (Metal / Vulkan / DX12 via wgpu).

  1. 1. Install Rust

    Install stable Rust with rustup. Kerabit pins the toolchain in rust-toolchain.toml — rustup will pick it up on first cargo in the repo. 

    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
# Windows: use the rustup-init.exe installer from rustup.rs
rustc --version

  2. 2. Clone the engine

    git clone https://github.com/AJpro774/kerabitengine.git
cd kerabitengine

  3. 3. Hello cube (~2 min after first compile)

    First build downloads crates and compiles wgpu — expect several minutes once. After that, examples are fast. 

    cargo run -p kerabit --example hello

    You should see an orange cube on a gray ground. Escape quits. Source: examples/hello.rs.

  4. 4. Open the editor

    cargo run -p kerabit-editor

    File → Open a level under games/reach/levels/. Orbit with right mouse, select an entity, press W for the move gizmo. See the Editor guide for Play, undo, and prefabs.

  5. 5. Play the flagship game (optional)

    cargo run -p reach
cargo run -p surge
# Visual trailer scene (when present):
cargo run -p showcase

    Players who only want Reach can grab a zip from Downloads (macOS + Windows when published).

Accept gate

If you completed steps 1–4 and saw the hello window plus the editor viewport, you are on the Summit stranger path. Next: API tour.
