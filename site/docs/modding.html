Community mods

Kerabit is open source, so extra content is just a git folder — not a store, launcher, or signed package. A pack is a directory with mod.kerabit.json plus scenes, Juni, and assets.

Install a pack

git clone https://github.com/someone/cool-maps.git mods/cool-maps
# or
git clone https://github.com/someone/cool-maps.git ~/.kerabit/mods/cool-maps

Kerabit also reads KERABIT_MODS (colon-separated on macOS/Linux, semicolon on Windows). Disable a pack from the editor Mods window; that writes ~/.kerabit/mods.json (Windows: %USERPROFILE%\.kerabit\mods.json).

Author a pack

{
  "id": "cool-maps",
  "name": "Cool Maps",
  "version": "0.1.0",
  "author": "you",
  "description": "Two extra scenes.",
  "game": "*",
  "scenes": ["scenes/entry.kerabit.json"],
  "homepage": "https://github.com/you/cool-maps"
}

id is kebab-case. game is reach, surge, spark, or *. Scene paths are relative to the pack root. First scene is the Play entry. In the editor: Mods → Show window → New pack, or ModIndex::scaffold / MCP kerabit_scaffold_mod.

Sample shipped in this repo: mods/hello-cube. Open or Play it from the Mods window.

Share it

Push the folder to GitHub. Add a row to community/catalog.json via pull request so others can find it. Games that care can call ModIndex::discover().extra_scenes("reach") to list extra levels.
